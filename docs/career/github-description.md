# GitHub description

## Short description

Hands-on FastMCP and AWS private-connectivity lab using CDK, VPC endpoints, EC2 Reachability Analyzer, and Kiro.

## Longer project pitch

aws-private-connectivity-mcp is a small portfolio project that explains MCP end to end while solving a realistic AWS networking problem. A local FastMCP server exposes tools that inspect AWS identity and infrastructure, diagnose EC2 and interface-endpoint paths, and verify S3 gateway endpoint routing. The lab includes deliberate security-group faults, normalized evidence, screenshots, and reproducible CDK infrastructure.

The project focuses on learning and operational clarity rather than autonomous mutation: the server recommends evidence-based remediation, while changes remain explicit and human-controlled.
